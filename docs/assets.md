# 项目素材

素材库显示项目中的图片、PDF 和 EPS 文件，与文件树使用同一份磁盘内容。

- 从素材库删除素材，会同时从文件树移除该文件。
- 从文件树删除素材文件或其所在文件夹，会同时移除素材库中的对应条目。
- 两处删除均需确认，文件移入项目的 `.texpro/trash/`，可从该目录找回。取消确认不会修改文件。
- 删除正在预览的素材时，预览自动关闭，回到写作界面。
- 从外部添加、修改或删除素材，应用可见时约 2.5 秒内刷新；返回应用时也会检查。
- 导入素材后，文件树和素材库一同更新。

删除不会自动改写正文里的 `\includegraphics` 等引用。仍被正文引用的文件删除后，需要自行修订对应引用。
