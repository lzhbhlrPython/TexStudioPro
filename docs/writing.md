# 连续写作

正文是唯一的文档。公式、表格、乐谱、电路、逻辑门、化学结构式、键线式和图表都写在当前 `.tex` 文件中；可视化工具只提供辅助操作。常用插入入口在「更多 → 插入」、命令面板及原生「插入」菜单。

## 输入与继续写作

- 普通表格直接点单元格输入。Tab / Shift+Tab 切换单元格，最后一格按 Tab 新增一行；Enter、Esc 或末行向下键回到正文。表格文字即时写回对应源码范围；输入的裸 `&` 和 `%` 自动转义。单元格也保留 TeX 命令，复杂排版可以点「编辑 TeX 源码」。
- 单元格中的 `$…$`、`\(...\)` 以及加粗、斜体等嵌套格式在离开编辑后正常渲染。点击公式进入该格对应源码片段。数学命令仍须使用合法的数学定界符，例如 `2.4 $\frac{1}{2}$`；不会将不合法源码悄悄改写成另一份文档。
- 乐谱插入后原位输入 TeX，点击已有谱面也回到文档输入；局部真实 TeX 预览跟随源文。需要点选音符、切换模板等操作时，显式打开「记谱辅助」。详见 [正文内乐谱](music.md)。
- 电路、逻辑门、结构式、键线式、TikZ 和图表插入后，光标留在可编辑的内容处。停止修改后更新局部预览；离开当前块恢复阅读形态。普通点击预览进入该处源码，按 Esc 或 Alt+Enter 继续后面的正文。
- 公式点击后原位修改 TeX。完整源码模式可随时通过 Cmd/Ctrl+Shift+M 切换。

这些操作使用文档的撤销和重做历史。单元格中的 Cmd/Ctrl+A 选择整个文档，便于跨内容复制；原位源码编辑保留 CodeMirror 的选择和剪贴板能力。图示与乐谱的预览失败只影响当前预览，原文仍可修改、保存。异步预览完成时补偿正文位置，继续滚动或移动光标会更新锚点。

## 智能输入与粘贴

设置中的「Markdown 输入快捷语法」和「智能粘贴」可分别关闭，默认开启。正文行首输入 `# ` 至 `###### `、`- ` / `+ ` / `* `、`1. ` / `1) ` 或 `> `，会转为对应 TeX 标题、列表或引用环境，光标留在内容处；输入完整的 `**粗体**`、`*强调*` 或 `` `代码` `` 会转为行内 TeX 格式。一次撤销可还原转换前的语法。

普通粘贴可将网页 HTML、Markdown 和矩形 TSV 表格转为 TeX。Cmd/Ctrl+Shift+V 按纯文本粘贴；应用内复制的 TeX 保留原文，智能粘贴作为一次编辑撤销。含原始 TeX 的剪贴板优先原样保留，数学、代码、注释及未闭合命令内部不触发正文转换。复杂网页表格与合并单元格回退原文，Markdown 嵌套列表不保证完整缩进层级；完整导入仍使用导入工具。

## 连续写作辅助

- **未写完也能继续输入**：半个命令、未闭合的公式保留可编辑源码，渲染失败时不替换成错误图片。中文输入法组合期间暂停局部预览与修订提示重排，组合结束再更新。
- **原位引用**：输入 `\ref{`、`\cite{` 或 `\includegraphics{`，候选显示章节/题注、文献标题/作者/年份或图片预览。方向键选择，Tab 或 Enter 接受；逗号分隔引用只替换正在输入的键。图片按当前章节的相对路径插入。悬停引用或脚注，或将光标放在其中按 Alt+F12，可就地查阅内容；引用只有点击「查看引用原文」才离开正文，Esc 关闭键盘查阅。
- **标签重命名**：光标放在标签或引用键上按 F2，或用「更多 → 编辑」及命令面板中的「重命名标签及引用」。工程内 `.tex` / `.ltx` 的标签声明和支持的引用命令一起更新到缓冲区，仍用正常保存流程写盘。原标签须有唯一声明，新标签不得重名；读取期间继续输入或切换工程会取消此次操作。撤销/重做成组处理受影响文件，若相关缓冲区已发生冲突则不覆盖新内容。
- **写作待办**：「更多 → 插入 → 留一条写作笔记」在当前位置附近插入 `% TODO: `，光标留在注释中。侧栏「写作笔记」汇总工程中的 TODO、FIXME、NOTE 和 DONE 注释；点击正文跳转，勾选写为 DONE，再次点击恢复 TODO。更改可撤销，不依赖专用文件格式，代码示例中的注释不计入。
- **完整内容移动**：光标放在章节或图表中，用 Alt+Shift+↑ / ↓，或「更多 → 编辑 → 整体上移/下移内容」。章节连同子节、图表、题注、标签和块内注释一起移动；同级章节不跨父章节。图表与相邻完整内容交换。无法确定完整边界时保持原文并提示。
- **正文内修订**：「更多 → 工具 → 在正文中修订」比较打开审阅时的上次保存版本；工程启用 Git 时也可选择提交，否则可选包含当前文件的内部快照。旧文显示在对应段落旁，分别「保留这处修改」或「恢复这段原文」。恢复是一次可撤销编辑；保留只更新本次审阅基线，不产生 Git 提交。关闭审阅回到普通写作。
- **就地编译提示**：光标进入报错行时，正文旁显示原始错误与常见原因。继续编辑后标明提示已过期，重新编译才刷新；提示不抢走焦点。完整日志仍在编译面板，最终行号以本次编译输入为准。
- **记住写作位置**：当前工程中切换文件会保留各自的光标、选择、滚动及撤销历史。引用、待办等定位后，用 Cmd/Ctrl+Alt+← 或「更多 → 编辑 → 返回刚才的写作位置」回到先前位置。最后编辑文件及各文件的光标、选择和滚动位置按工程保存在本机，重新打开或重启后恢复；恢复章节不会改变工程主文件。撤销历史只在当前会话保留，不跨重启恢复；外部改写造成缓冲区不一致时重新载入该文件状态。
- **拖图后接着写**：粘贴图片、拖入图片或从素材库插入时，先存入素材目录，再插入完整 `figure`、图片路径和唯一 `fig:` 标签，光标进入题注。拖入点位于已有图表内时放在完整块之后，主文件导言区内则放在正文起点。异步导入期间切换文件/工程或修改目标范围时，不覆盖新内容；已保存图片留在素材库。撤销插图只撤销正文，不删除图片文件。

以上操作都在当前文档中完成；改动仍需正常保存。外部宏或复杂 TeX 不会被猜测并重写为简化模型。

## 可选辅助工具

公式编辑器、表格编辑器和各类工作室放在「工具」及原生「可视化辅助」中。主动打开辅助工具时记录当前文件与源文范围；插入后回到该位置。源文范围跟随周围正文变化；若目标本身已被修改、当前文件或工程已切换，则拒绝覆盖并提示重新打开。取消辅助工具会返回文档位置。

这些工具仍可能使用浮层或独立面板，适合明确需要可视调整的情况。普通插入和修订不依赖它们。

## 主文件与保存

新插入内容所需的宏包补入工程已选主文件。编辑章节时不切换标签，Cmd/Ctrl+S 保存当前工程全部脏缓冲区。没有明确主文件时提示选择，不擅自将章节当作入口。编译继续沿用工程主文件与既定工具链。

## 安全边界

直接单元格编辑适用于可明确映射的 `tabular`、`tabularx` 和简单 `longtable`。合并单元格、嵌套环境、注释影响行结构、复杂列类型等保留原始 TeX 编辑，避免用简化模型重写内容。宽度列仍可写文字，复杂列格式在源码中调整。

图示预览使用选定主文件的导言区与可用的本地 TeX 环境，按原始 TeX 尺寸和屏幕密度显示，并适配正文可用空间；自定义宏、外部文件或特殊引擎可能影响局部预览。完整工程 PDF 是最终排版依据。乐谱的高级记谱能力及边界见乐谱文档。

## 配色与排版颜色

黑白 TeX 预览的墨色跟随纸面、工作室和夜间主题，抗锯齿与灰阶保留为透明度。带明确配色的图表保留原始颜色，使用局部浅色纸面保证彩色线条及黑字可读，不做整体反色。主题切换不重编译，也不修改 TeX 或导出 PDF 的颜色。

## 文件树直接新建

左侧「项目」标题旁的 + 在工程根目录新建文件；文件夹或已有文件的右键菜单在该目录中新建。文件名直接在树中输入，Enter 或勾号创建，Esc 取消。同名文件不会被覆盖，错误提示保留当前输入。无扩展名时默认补 `.tex`；`.bib`、`.sty` 等按名称创建空文件，不插入章节命令。新文件创建后直接打开写作，工程主文件保持原选择。新建文件夹也使用同一原位输入流程。

其余已知交互问题与转换边界见 [写作交互一致性检查](interaction-audit.md)。跨文件切换保留各自编辑状态；当前没有将多个文件合并为连续正文的编辑模式。
