# 写作交互一致性检查（2026-10-23）

本轮静态检查覆盖 `src/components`、编辑器扩展、应用状态、剪贴板与项目文件操作；原生界面验证集中在下面列出的写作链路，不代表所有辅助工具都经过逐项人工验收。

## 本轮已处理

- 命令面板的标题、说明、语言入口与搜索使用同一界面语言；补全说明、空状态、提示与关闭按钮补齐翻译。快捷键按平台显示。
- Markdown 输入快捷语法、富文本/Markdown/矩形表格粘贴转换为 TeX；保留直接 TeX、数学、代码、注释及内部复制的原文，转换可以撤销。
- 本机记录工程最后编辑文件、光标、选择和滚动位置；重新打开不改变工程主文件。跨重启不恢复撤销栈。
- 引用和脚注在当前段落旁查阅，显式跳转才离开正文；标签重命名维护工程内 TeX 引用，并提供成组撤销/重做。
- 异步预览更新补偿正文位置；用户滚动或移动光标会更新锚点。
- 用应用自己的输入框替代 Electron 不支持的 `window.prompt`，保持主题、键盘取消及焦点恢复。
- 新建文献文件拒绝覆盖已有文件。文件移动、重命名、删除在保存失败时停止；删除确认汇总影响，回收站接收已保存内容。

## 确认仍需后续处理

1. **文件路径重命名后的打开缓冲区同步**：`electron/services/tex.cjs` 会修改磁盘中的路径引用，而 `src/App.tsx` 的文件/目录重命名与移动操作未同步重新读取其他已打开文件。之后保存这些缓冲区可能恢复旧路径。需要把磁盘引用改写与所有打开缓冲区作为一次事务处理，并覆盖操作期间继续输入的情况。这不同于本轮新增的标签重命名，后者在缓冲区中更新。
2. **旧辅助面板的键盘一致性**：例如 BackupPanel、BibManager、TemplateGallery 等尚未统一接入焦点约束和完整 dialog 语义；本轮仅补齐部分关闭按钮名称。应沿用现有共享焦点机制逐步统一。
3. **首次加载体积**：生产构建仍提示较大的主 JavaScript 分块。后续可按需加载辅助工作室；不能让拆包影响首次进入正文的速度或编辑状态。

## 转换边界

智能格式转换采用保守识别：混合原始 TeX 的剪贴板优先保留原文；合并单元格与复杂网页表格回退原文；Markdown 嵌套列表不保证完整保留缩进层级。它不是完整 Markdown 导入器。文件内的自定义宏和复杂 TeX 始终以源文为准。

## 验证入口

`npm run typecheck`、`npm run test:regression`、`npm run build`、`npm run verify:release`；原生写作链路为 `npm run test:flow:ui`，已有连续编辑回归为 `npm run test:continuity:ui`。
