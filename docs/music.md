# 正文内乐谱

乐谱是写作页中的内容块，与正文、公式、表格共用一个编辑器。入口是「更多 → 插入乐谱」、命令面板或原生「插入」菜单；没有独立工作间。

点击谱面展开当前块的记谱控件，完成编辑后点「完成」或回到正文。控件支持点选音符、方向键改变音高、添加/删除音符、时值、附点、变音记号、延音线、歌词音节、力度与和弦标记。五线谱可添加和弦附加音（例如 `E4, G4`）；六线谱可调整弦与品位。编辑共用正文的撤销历史和保存流程。

模板包括旋律与歌词、钢琴、四部合唱、指挥总谱、简谱和吉他六线谱。一个块最多八个声部，各声部共享拍号和调号；「谱面范围」切换总谱或某个分谱，原始声部数据不会丢失。跨小节长音自动拆分并连接延音线；短声部及末小节在排版时补齐休止符，编辑区会提示末小节不足。

## 源码与编译

插入时会向工程已选主文件添加 `musixtex` 和 `tikz` 宏包，乐谱插入当前编辑文件的光标位置。光标在主文件导言区时，插入点移到 `\begin{document}` 后。章节文件保持章节身份，完整 PDF 始终从工程主文件编译。

块本体是普通 TeX，编辑数据保存在 `% texpro-music-data:` 注释中；离开应用仍可编译。块工具中的源码按钮可以定位到正文源代码；「高级 TeX」也可直接修改块内 TeX。手写改动优先保留，与数据不再一致时停用可视化控件，避免覆盖手写内容。

五线谱由 MusiXTeX 排版，简谱与六线谱由 TikZ 排版。需要 TeX Live 或 MiKTeX 中的 `musixtex`、`pgf` 及既有 `latexmk`，不需要 LilyPond 或其他制谱程序。MusiXTeX 使用 `latexmk → texlua musixflx.lua → latexmk`，预览和完整 PDF 都经过间距计算。

内嵌预览在停止修改后约 600 毫秒开始编译，耗时取决于 TeX，编辑记谱立即反馈。预览使用独立辅助目录，不改工程主文件和编译状态；切换文档会取消旧预览。失败时显示错误并移除旧谱面，正文继续可编辑。成功 PDF 缓存在工程的 `.texpro/music-previews/`，可随时删除。

## 当前边界

可视化编辑覆盖顺序音符、基本和弦和最多八声部；同一谱表的独立复调、连音组、自动连梁、复杂装饰音、自动移调与吉他多弦同时音尚需高级 TeX。简谱使用大调首调记谱，和弦附加音目前以自然音名录入。速度是谱面标注，没有播放功能。

内嵌预览使用独立的最小文档，保留真实 TeX 记谱，但正文的字体、页宽及自定义宏以完整工程 PDF 为准。中文歌词预览使用 XeLaTeX 与 TeX 自带 Fandol 字体；工程最终排版也需正确配置中文宏包、字体和编译引擎，例如 XeLaTeX 与 `ctex`。预览不自动改动正文的字体方案。

## 验证

- `npm run test:regression`：数据恢复、源码优先、时值跨小节、分谱及间距服务。
- `npm run test:music`：六种模板、中文合唱、和弦/跨小节/分谱的真实 TeX 编译，以及并发缓存和取消隔离。
- `npm run test:music:ui`：Electron 内的插入、保存、撤销、源码切换、三主题与窄窗口、失败恢复。需先 `npm run build`。
